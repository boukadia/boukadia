## 🚀 Projets réalisés

### 🎬 DIGITAL DABA — CMS et plateforme e-commerce

Développement d'un système de gestion de contenu permettant d'administrer des produits, des catégories, des commandes, des utilisateurs, des avis et différents contenus du site.

- Développement du back-office avec **Laravel, PHP et FilamentPHP**.
- Gestion des données avec **MySQL**.
- Création d'interfaces avec **Blade, Bootstrap et CSS**.
- Utilisation de **Git, GitHub et Jira** pour le suivi du développement.

**Technologies :** Laravel · PHP · FilamentPHP · MySQL · Blade · Bootstrap

### 🏥 MediSync — Application de gestion médicale

Développement d'une application web de gestion médicale avec une API backend et une interface frontend permettant de gérer différents profils d'utilisateurs et des fonctionnalités liées au suivi médical.

- Développement de l'API avec **Node.js, Express.js et MongoDB**.
- Modélisation des données avec **Mongoose**.
- Développement de l'interface avec **React, TypeScript et Bootstrap**.
- Utilisation de **JWT** pour l'authentification.
- Documentation des endpoints avec **Swagger**.

**Technologies :** React · TypeScript · Node.js · Express.js · MongoDB · Mongoose · Bootstrap · JWT · Swagger
